# Проверка качества

Проверки предназначены для публичного сайта и учебной модели.
Они не сертифицируют торговую систему.

| Команда             | Проверяет                                             |
| ------------------- | ----------------------------------------------------- |
| `npm run check`     | TypeScript и Astro                                    |
| `npm test`          | Полнота данных, лимиты, версии, неизменность проектов |
| `npm run build`     | Статическая сборка                                    |
| `npm run test:site` | Ссылки, метаданные, запрещённые файлы, границы сети   |
| `npm run test:e2e`  | Интеракции, адаптивность, режим без JS, HTTP-статусы  |

Браузерные ширины: 320, 360, 390, 768, 1024, 1440 px.
Проверяется полный цикл трёх источников, отказ, запрос уточнения и сброс
после перезагрузки. Тест не обращается к внешним финансовым сервисам.

Перед публикацией также требуется просмотр страниц, проверка телефонов и
ссылок, редакционная проверка утверждений и аудит файлов Git.

Не заявляем конкретные Lighthouse scores, WCAG-сертификацию или
эффективность стратегии без отдельного измерения.

Для этого TypeScript/Astro-релиза Python-проверки `ruff` и `pytest` не
применяются: Python-код и исследовательская система не изменялись.
