# Instructions for this public showcase

Read `SPEC.md`, `.env.example` and relevant tests before editing.

- Keep everything suitable for a public repository.
- Never copy material, code or Git history from another private project.
- Do not access real environment files, broker credentials or research datasets.
- All examples must remain synthetic; never add network calls to the demo.
- No real order execution, account connections, payment or lead collection.
- Never replace manual confirmation or independent risk checks with LLM judgment.
- Do not claim future capabilities, profit, partnerships or test scores as facts.
- Keep the site static, dependencies small and content readable without JavaScript.
- Preserve three equal author modes and the immutable draft boundary.
- Run `npm run verify`; run relevant Playwright tests for interaction/layout changes.
- Publish only `dist/`. Do not change existing hosting services or DNS records
  unrelated to this site.
- Never choose an open-source license without the owner's decision.
